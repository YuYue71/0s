# 英文字根大全
> 英文解構系統

---

## 使用方法

把每個單字想像成拼圖，用字根**拆解**它：

```
unreadable = un + read + able = 否定 + 讀 + 能夠 = 無法閱讀的
initialization = init + al + ize + ation = 開始 + 使成為 + 行為 = 初始化
decompression = de + compress + ion = 解除 + 壓縮 + 名詞 = 解壓縮
```
