第二章：色彩系統設計

色彩是設計中最具表現力的工具。一個精心設計的色彩系統能提升用戶體驗並強化品牌認同。

主色調

代表品牌核心特性的色彩，用於按鈕、標題等關鍵元素

輔助色

配合主色調的補充色彩，用於強調積極或成功狀態

背景色

低飽和度、高明度的色彩，為內容提供舒適的呈現空間

中性色

黑、白、灰等色彩，提供視覺層次與可讀性

常見錯誤
  • ✗ 使用過多相似的顏色
  • ✗ 忽視色彩的無障礙設計
  • ✗ 色彩與內容語義不符
  • ✗ 對比度不足導致閱讀困難
最佳實踐
  • ✓ 建立 3-5 色的色彩調色板
  • ✓ 遵循 WCAG 無障礙對比度標準
  • ✓ 色彩使用與功能狀態對應
  • ✓ 考慮色盲用戶的體驗

第三章：排版與字體系統

好的排版是用戶舒適閱讀的基礎。通過建立清晰的字體層次，可以引導用戶注意力並改善整體可讀性。

排版的挑戰

視覺混亂

字體層級不清，用戶無法快速定位信息

可讀性差

行距不當導致視覺疲勞

響應式困難

在不同屏幕尺寸下排版失效

最佳解決方案

建立字體層級

H1-H6 與 Body、Small 等標準尺寸

優化行距和字距

1.5-1.8 倍行高提升舒適度

使用響應式單位

rem 與 em 實現跨設備適配

標題字體

選擇具有個性的字體，增加視覺吸引力

正文字體

優先選擇易讀的字體，確保長文本可閱讀

等寬字體

用於代碼、數據等需要精確對齐的內容

第四章：空間設計與網格系統

正確的間距和網格系統能創造秩序感，提升用戶體驗的一致性和專業度。

無序設計
  • ✗ 間距隨意，缺乏規律
  • ✗ 元素對齊不一致
  • ✗ 視覺很難構建層級
  • ✗ 難以維護和擴展
系統化設計
  • ✓ 採用 8px 或 4px 的基礎單位
  • ✓ 所有元素按網格對齊
  • ✓ 間距層級清晰（XS, S, M, L, XL）
  • ✓ 易於團隊協作和維護

8px 網格系統

基礎單位為 8px，所有元素按倍數排列

邊距管理

外邊距與內邊距的標準化定義

視覺層次

通過空間創造元素間的優先級關係

響應式適配

不同屏幕尺寸下的自適應間距方案

第五章：可複用組件系統

組件化設計是現代設計系統的核心。通過可複用的組件提高效率，確保一致的用戶體驗。

分散設計的問題

重複工作

相同組件在多處設計和編碼

版本分歧

組件風格不一致，維護困難

組件系統

統一組件庫

集中管理所有可複用元素

一致性保障

組件更新自動同步到全部文件

設計系統

按鈕組件

Primary, Secondary, Danger 等多種狀態

文本輸入

支持多種狀態與驗證提示

卡片組件

靈活的容器組件，支持自定義佈局

導航模式

Tab, Menu, Breadcrumb 等導航方案

第六章：交互動畫設計

精心設計的動畫能增強用戶體驗，傳達反饋並引導用戶操作流程。

懸停反饋

顏色變化、陰影加深提示可交互狀態

點擊反應

瞬間的視覺反應提升交互感

過渡動畫

頁面切換與元素出現的流暢銜接

狀態提示

加載、成功、失敗等狀態的視覺反饋

常見誤區
  • ✗ 過度動畫，分散注意力
  • ✗ 動畫速度不合理
  • ✗ 沒有考慮無障礙用戶
  • ✗ 頻繁出現相同動畫
最佳實踐
  • ✓ 動畫持續時間 200-500ms
  • ✓ 使用緩動函數優化過渡
  • ✓ 支持 prefers-reduced-motion
  • ✓ 動畫增強而非取代功能

第七章：無障礙與包容性設計

無障礙設計不是附加功能，而是現代設計的必要標準。它確保所有用戶都能平等地使用產品。

視覺無障礙

足夠的色彩對比度，支持高對比度模式

聽覺無障礙

提供字幕、轉錄和文字替代

運動無障礙

支持鍵盤導航，足夠大的點擊區域

認知無障礙

清晰的語言，簡單的流程和結構

無障礙的障礙
  • ✗ 色彩對比度低於 4.5:1
  • ✗ 忘記為圖片添加 alt 文本
  • ✗ 無法僅用鍵盤操作
  • ✗ 忽視屏幕閱讀器相容性
WCAG 標準
  • ✓ 遵守 WCAG 2.1 AA 標準
  • ✓ 完整的語義 HTML 標記
  • ✓ 支持鍵盤和屏幕閱讀器
  • ✓ 提供多種形式的內容
